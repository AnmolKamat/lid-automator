MacBook Lid Automator

Detect continuous physical MacBook lid angles and trigger shell commands, native notifications, and system shortcuts without wake latency or background battery drain.

$brew tap AnmolKamat/tap && brew install lid-automator

Interactive Simulator

Adjust the slider to simulate lid movement across active rule boundaries.

Installation

Option A: Homebrew Tap (Recommended)

$brew tap AnmolKamat/tap && brew install lid-automator

Option B: Quick Install (curl)

$curl -fsSL https://raw.githubusercontent.com/AnmolKamat/lid-automator/main/install.sh | bash

Option C: Build from Source

git clone https://github.com/AnmolKamat/lid-automator.git
cd lid-automator
swift build -c release
sudo cp .build/release/lid-automator /usr/local/bin/

CLI Reference

lid-automator status

Show current lid angle, gauge meter, daemon status, and active configuration file.

lid-automator run

Run interactive listener in foreground. Move laptop lid to view live stream.

lid-automator start

Register and start daemon via LaunchAgent (runs 24/7, persists on login).

lid-automator stop

Stop running background daemon service.

lid-automator list

Print formatted table of all automations, triggers, and active status.

lid-automator logs -f

Live stream execution events and trigger logs from daemon.

lid-automator config --choose

Point daemon to a custom config file path with automatic hot-reloading.

lid-automator --version

Print installed application version number.

Configuration

Config file lives at ~/.lid-automation/config. Changes are hot-reloaded automatically by the daemon without restarts.

[
  {
    "name": "Lock Screen on Low Angle",
    "angle": "<40",
    "trigger": "enter",
    "notify": true,
    "script": "builtin:lock",
    "enabled": true,
    "rules": {
      "cooldown": 5,
      "rearm": 45
    }
  },
  {
    "name": "Volume 80% on Open",
    "angle": ">100",
    "trigger": "enter",
    "notify": true,
    "script": "builtin:volume 80",
    "enabled": true,
    "rules": {
      "cooldown": 2,
      "rearm": 95
    }
  },
  {
    "name": "Pause Docker Containers",
    "angle": "30-50",
    "trigger": "closing",
    "notify": "Docker containers paused",
    "script": "docker ps -q | xargs -r docker pause",
    "enabled": false,
    "rules": {
      "days": ["mon", "tue", "wed", "thu", "fri"],
      "time": "9am-6pm",
      "cooldown": 10
    }
  }
]

Supported Devices

Requires Apple's Lid Angle Sensor (LAS) via Apple SPU (0x8104 / 0x008A).

Hardware Model Status Notes
MacBook Pro 14" Supported All Apple Silicon models (M1 Pro/Max through M5 series)
MacBook Pro 16" Supported All Apple Silicon models (M1 Pro/Max through M5 series)
MacBook Air 13" Supported Redesigned flat chassis (M2, M3, M4, M5 series)
MacBook Air 15" Supported All 15-inch models (M2, M3, M4, M5 series)
MacBook Air 13" (M1, 2020) Unsupported Wedge-shaped chassis uses binary magnet switch
MacBook Pro 13" with Touch Bar Unsupported Legacy 13" chassis (M1 2020, M2 2022)
Desktop Macs (Mini, Studio, Pro, iMac) Unsupported No display hinge sensor

Technical Architecture

IOKit HID

Connects to AppleSPUHIDDevice (Vendor 0x05AC, Product 0x8104, Usage 0x008A) via IOHIDManager.

Zero CPU Idle

Combines asynchronous input report interrupts with a 100ms fallback watchdog for background persistence.

Hot Reload

Dispatches GCD file-system event monitoring (DispatchSourceFileSystemObject) to reload config on modification.
